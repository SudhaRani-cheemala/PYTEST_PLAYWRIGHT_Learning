What is XFail?

xfail means:

We expect this test to fail.

For example, suppose there is a known bug in the application.


import pytest

@pytest.mark.xfail(reason="Known login bug")
def test_login():
    assert 1 == 2

Why use XFail?

Imagine your development team knows:

"There is a known bug in the payment calculation."

You still want to keep the test in your automation suite.

Instead of deleting the test:   


def test_payment():
    assert actual == expected

@pytest.mark.xfail(reason="Known payment calculation bug")
def test_payment():
    assert actual == expected    

    Now the test remains in your framework, but Pytest understands that the failure is expected.


 Skip vs XFail

This is very important for interviews.

Skip	XFail
Test is not executed	Test is executed
We don't want to run it	We expect it to fail
Result = SKIPPED	Result = XFAIL
Useful for unavailable/not-applicable tests	Useful for known bugs
Easy way to remember:

Skip → Don't run it
XFail → Run it, but I expect it to fail


What happens if XFail unexpectedly passes?

This is an interesting interview point.

Suppose:

@pytest.mark.xfail(reason="Known bug")
def test_login():
    assert 1 == 1

The test actually passes.

Pytest can report it as:

XPASS

Meaning:

Expected failure, but the test passed.

This can be useful because it may indicate that the underlying bug has been fixed.


Real Automation Example

Imagine you're testing an e-commerce application.

Payment feature unavailable
@pytest.mark.skip(reason="Payment environment is unavailable")
def test_payment():
    pass

You don't want to run the test.

Known payment bug
@pytest.mark.xfail(reason="Known payment calculation defect")
def test_payment_calculation():
    assert actual_amount == expected_amount

You want the test to run, but you already know it currently fails.



Interview Questions
Q1. What is skip in Pytest?

"skip is used to prevent a test from executing. It is useful when a test is temporarily unavailable, not applicable, or a required feature/environment is unavailable."

Q2. What is skipif?

"skipif conditionally skips a test based on a condition."

Example:

@pytest.mark.skipif(condition, reason="...")
Q3. What is XFail?

"xfail is used when we expect a test to fail, usually because of a known defect or incomplete functionality."

Q4. What is the difference between skip and xfail?

"skip means the test is not executed, whereas xfail means the test is executed and we expect it to fail."

Q5. What is XPASS?

"XPASS occurs when a test marked as XFail unexpectedly passes."
